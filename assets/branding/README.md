# Brand assets

This directory contains the official, repository-hosted Agent Entrepreneur identity assets.

## Logo

- `agent-entrepreneur-logo.svg` — scalable horizontal master lockup.
- Recommended use: README, documentation, project pages and release notes.
- Preserve the SVG aspect ratio; do not recolour or distort the mark.
- Primary colours: white `#FFFFFF`, violet `#7C3AED`, magenta-violet `#D946EF`, and near-black `#08080D`.

## Banner artwork

The cinematic global-founder banner is a separate raster artwork and is not included in this commit. It should be added only after the original export is uploaded and checked for image rights, portrait accuracy, legibility and GitHub crop safety. Any identifiable public-figure portraits must be appropriately licensed and must not imply endorsement or affiliation.

## Brand usage

Use the product name **Agent Entrepreneur** consistently. The descriptor is **An Open-Source AI System for Entrepreneurs**. Do not claim endorsement by featured entrepreneurs, autonomous capabilities not present in the software, or product outcomes that have not been verified.
