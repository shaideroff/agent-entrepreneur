# Support Agent Entrepreneur

Agent Entrepreneur is an open-source, local-first, model-independent MCP server for entrepreneurial intelligence. It helps a connected AI client structure business context, analyse supplied metrics, evaluate decisions, plan execution and review outcomes.

If this project is useful to you, [sponsor its development on GitHub](https://github.com/sponsors/shaideroff).

## Why sponsorship matters

Sponsorship helps sustain the work required to keep a useful open-source project reliable over time. The priorities are:

1. **Maintenance and compatibility** — keep the MCP server dependable across supported Python versions and MCP SDK releases.
2. **Security and reliability** — improve dependency hygiene, protocol validation, test coverage, backup integrity and safe defaults.
3. **Documentation and adoption** — make installation, configuration and integration easier for individual developers and teams.
4. **Entrepreneurial knowledge quality** — expand the reference registry through traceable research, clear attribution and evidence grading.
5. **Practical capabilities** — improve business diagnosis, decision evaluation, specialist workflows and execution planning based on validated user needs.

## Who can support it

- **Individual developers and founders** can help sustain an independent tool they find useful.
- **Open-source users** can contribute toward maintenance, testing and documentation.
- **Teams and organisations** can support the continued availability of a model-independent MCP server without tying it to a single model provider.

Choose any available sponsorship option on the [GitHub Sponsors profile](https://github.com/sponsors/shaideroff). Contributions are voluntary; there is no required amount.

## Funding and accountability

Sponsorship is support for ongoing project development. It is not a purchase, investment, loan, donation receipt, consulting agreement, service-level agreement, or promise of financial return. A sponsorship does not guarantee a particular feature, delivery date, private support, influence over project decisions, or preferential issue handling.

Project priorities remain guided by usefulness to the wider community, technical merit, security, maintainability and the published project scope. Sponsor recognition, where offered, is opt-in and subject to the sponsor's preferences.

Development progress and material changes should be communicated through the public repository, issues, pull requests, releases and changelog. Sponsorship does not replace normal community contribution channels.
