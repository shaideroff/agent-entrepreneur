# Privacy notice — Agent Entrepreneur Plugin

**Publisher:** S Haider (intended publisher; public-directory identity verification is a separate OpenAI Platform requirement).

**Scope:** This notice describes the Skills-only Agent Entrepreneur Plugin package. It does not replace the privacy notices of ChatGPT, Codex, or any connected tool provider.

## Data collected by this Plugin

The Plugin package contains reusable workflow instructions. It does not operate a hosted service, run analytics, set cookies, maintain user accounts, receive telemetry, or independently collect or store business information.

When a user invokes a Skill, the user-provided prompt, files, and resulting conversation content are processed by the ChatGPT or Codex host under that provider's applicable terms, privacy controls, workspace policies and settings. If the user chooses to use web search, connected apps, file tools or other services, those providers' terms and privacy practices also apply.

## Data handling

- The Skills instruct the model to use only information needed for the requested task.
- The Skills do not request passwords, API keys, payment credentials or unrelated sensitive personal information.
- Users should remove confidential, regulated or third-party personal data unless it is necessary and they are authorised to share it.
- The Plugin does not send data to an Agent Entrepreneur-operated endpoint.
- The separate open-source MCP server may persist user data locally when installed and configured by the user; consult the repository documentation before using that separate software.

## Security and retention

The Plugin publisher does not control the host provider's retention, security, training or account settings. Users should consult the host provider's current privacy documentation and their organisation's policies.

## Contact and support

For questions about the Plugin package, use the repository issue tracker: https://github.com/shaideroff/agent-entrepreneur/issues

## Changes

This notice may be updated when the package's data flows change. A material change to data collection or external services requires a fresh privacy review before release.
