## MCP STDIO test scope

The existing tests/test_mcp_protocol.py starts the server as a subprocess, initializes a real MCP ClientSession, lists tools and calls each of the six experience-agent tools. The latest branch change adds a separate STDIO test for:

- invalid discovery status;
- empty profile identifier;
- oversized recommendation objective;
- oversized council-preparation objective;
- council contribution count above the five-agent limit;
- empty direct work-packet identifier;
- deterministic repeated discovery and council recommendation responses.

The added boundary assertions passed in CI run 42716582306 (MCP SDK 1.9.0 and latest). The full suite passed in CI run 42716582336 on Python 3.11 and 3.12. Ruff, mypy, pytest and architecture-graph checks all completed successfully. The independent TypeScript MCP client test passed in run 42716582579. Reproducible wheel/sdist builds and installed-package tests passed in run 42716582612.
