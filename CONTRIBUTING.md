# Contributing

Install Python 3.11+, then run `python -m pip install -e '.[dev]'`.

Before a pull request, run `ruff check .`, `ruff format --check .`, `mypy src` and `pytest -q`.

Keep the MCP interface compact. Add tests for behavior changes. Never fabricate biographies, quotations, business results or source references. Attribute methods and provide evidence provenance. Do not publish private user/customer data or introduce mandatory hosted providers. Preserve human approval gates.
